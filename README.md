# Rails + Docker app

このリポジトリは、**Docker** を利用して構築された **Rails** アプリケーションを、**Heroku** へデプロイしたプロジェクトです。  
アプリケーションのデモはこちらからアクセスできます:  
[https://stormy-gorge-33057-aca6953c3324.herokuapp.com/](https://stormy-gorge-33057-aca6953c3324.herokuapp.com/)

## Overview

- Rails 7.2.0
- Ruby 3.3.4
- **Docker + Docker Compose**  
- **Heroku** デプロイ
- 画像アップロードは **Cloudinary** と **Active Storage** を利用

## Key Features

- **管理者画面**  
  - 管理画面 (/admin/products) で商品一覧・追加・編集・削除が可能  
  - ユーザーの詳細も確認可能

- **ユーザー画面**
  - ECサイトの様に商品をカートに入れることができる(決済は行われない)
  - ログイン、ログアウト機能
  - カート機能
